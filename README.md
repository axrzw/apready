# AP جاهز

برنامج واحد يسهّل لعب Archipelago مع الشباب: تختار لعبتك وتضغط العب.

## للاعب
1. شغّل `APReady.exe`، ويفتح لك صفحة في المتصفح.
2. اكتب اسمك واختر لعبتك.
3. **Death Link** شغال من نفسه، طفّه لو ما تبيه.
4. اضغط **جهّز اللعبة** (أول مرة بس).
5. اضغط **طلّع ملفي للمستضيف** وارسل الملف في ديسكورد.
6. لما يرسل لك المستضيف عنوان الروم، الصقه واضغط **▶ العب**.

## للمستضيف
1. تبويب **أنا المستضيف** > **افتح مجلد اللاعبين**، وحط فيه ملفات الشباب وملفك.
2. اضغط **ولّد السيد وجهّز الروم**.
3. ارفع الملف في الصفحة اللي تنفتح، واضغط Create New Room، وارسل العنوان للشباب.

## الألعاب
تيراريا، إلدن رنق، سيكيرو، هيتمان، ريزدنت إيفل 2 و 3، كب هيد.
كلها **تجريبية** لين نجربها فعلياً. لإضافة ألعاب شوف `ADDING_GAMES.md`.
