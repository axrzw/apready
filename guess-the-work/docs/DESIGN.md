# DESIGN.md: هوية «خمّن العمل»

## الاتجاه
**صالة عرض بعد إطفاء الأنوار، وشارة بداية أنمي.** خلفية شبه سوداء دافية، وتباين محسوب، ولون واحد مميز (كهرماني «لمبة الشاشة») يتكرر بانضباط، وأحمر قرمزي للإشارات فقط (الوقت، الخطأ). الصور والبوسترات هي البطل: تاخذ أكبر مساحة، والواجهة حولها هادية، رفيعة، وبدون زخرفة.

المرجعيات: شارات البداية (عناوين كبيرة بخط عرض، خطوط أفقية رفيعة، ترقيم إطارات)، وشريط السينما (letterbox) لحظة الكشف، وحبيبات فيلم خفيفة جداً.

## ممنوع
- إيموجي أو رموز تعبيرية في أي نص أو زر أو عنوان أو نتيجة أو بطاقة مشاركة. فيه اختبار يفشل لو انضاف واحد (`apps/web/test/no-emoji.test.ts`).
- تدرجات بنفسجية، وظلال كبيرة، وبطاقات متشابهة بزوايا دائرية كبيرة، وألوان صارخة، وأيقونات كرتونية.
- خطوط النظام، أو أكثر من عائلتين.

|---|---|---|
| `--bg` | `#0B0B0D` | الخلفية |
| `--bg-raise` | `#111114` | الهيدر والأشرطة |

| `--line` | `rgba(255,255,255,.07)` | الحدود الرفيعة |
| `--line-strong` | `rgba(255,255,255,.14)` | حدود التركيز والتمرير |
| `--text` | `#EEEAE2` | النص (أبيض دافي) |
| `--muted` | `#9C978E` | النص الثانوي |
| `--faint` | `#5F5B55` | التسميات الصغيرة |
| `--accent` | `#E9B44C` | اللون المميز الوحيد: الأزرار الرئيسية، المؤشر، النقاط |
| `--accent-ink` | `#1A1306` | النص فوق الكهرماني |
| `--signal` | `#D9503F` | الوقت ينتهي، الإجابة الخاطئة، الحذف |
| `--ok` | `#5BC08E` | الإجابة الصحيحة (لحظياً فقط) |

- **الزوايا:** 4px للعناصر الصغيرة، و8px للوحات والصور. لا شي فوق 12px.
- **الظلال:** بدون، إلا ظل خفيف للصورة البطلة (`0 30px 80px -40px rgba(0,0,0,.8)`).
- **المسافات:** شبكة 4px (4، 8، 12، 16، 24، 32، 48، 64).
- **الحدود:** 1px بـ `--line`، والتمرير يرفعها لـ `--line-strong`.

## الخطوط
- **العناوين (عرض):** Reem Kufi 500–700. مقاسات 56 / 40 / 28 / 20، وتباعد أسطر ضيق (1.1).
- **النصوص:** IBM Plex Sans Arabic 400/500/600. مقاسات 16 / 14 / 12.
- **الأرقام:** دائماً `tabular-nums` (المؤقت، النقاط، الترتيب)، بأرقام لاتينية متناسقة.
- **التسميات الصغيرة:** 11–12px، وزن 600، تباعد حروف 0.08em للاتيني، ولون `--faint`. أسلوب ترقيم الإطارات: «٠٣ / ١٠»، «TAKE 2».

## الأيقونات
`lucide-react` فقط، stroke 1.5، ومقاس 16/20/24. أيقونة كل طور معرّفة في `MODES[].icon` في `packages/core/src/questions.ts`. الصور الرمزية للاعبين = أيقونة Lucide داخل مربع بلون اللاعب.

## الحركة (Framer Motion)
- **الانتقال بين الأسئلة:** fade + انزلاق 16px بـ 280ms ease-out.
- **الكشف التدريجي:** الصورة الجديدة تذوب فوق القديمة (crossfade 400ms).
- **لحظة الكشف:** شريطا letterbox يدخلون من فوق وتحت، والعنوان يطلع حرف وراء حرف (stagger 18ms)، والنقاط تعدّ لفوق (count-up 700ms).
- **لوحة الصدارة:** إعادة الترتيب بـ `layout` (spring خفيف).
- `prefers-reduced-motion`: كل الحركة تصير fade بسيط أو بدون حركة (`MotionConfig reducedMotion="user"`).

## الصوت
مؤثرات قصيرة مولّدة بـ Web Audio (بدون ملفات): صحيح (نغمتين صاعدة ناعمة)، وخطأ (نقرة منخفضة)، وآخر ٥ ثواني (تكّة خفيفة)، وانتهاء الوقت. زر كتم في الهيدر، ومحفوظ في المتصفح.

## لمسة كل طور (ضمن نفس الهوية)
| الطور | اللمسة |
|---|---|
| الأطوار الصوتية (أوبننق، إندنق، أوست، صوت معدّل، أغنية، صوت المشهد) | موجات صوت متحركة بالكهرماني، والخلفية «غرفة تسجيل» داكنة |
| البوستر، الصورة، الظل، العيون | إطار عرض بزوايا تصويب (crop marks) حول الصورة |
| المشهد | شريط letterbox دائم، وترقيم إطار |
| الوسوم، القصة | ورقة سيناريو: نص بخط النصوص على سطح أفتح قليلاً، والأسماء المحجوبة أشرطة سوداء |
| الرسّام | ملمس ورق دافي (`#F2EDE3` مع حبيبات) للوحة الرسم والمعرض |
| الواصف | إضاءة مسرح: بقعة ضوء دائرية من فوق على العنصر، والباقي معتم |
| اشرح بالكاميرا | استوديو تصوير: زوايا عدسة، نقطة REC، وشبكة الأثلاث |

- **تير ليست:** ألوان التيرات (اختيار صاحب المشروع): S أحمر `#C8625A`، وA برتقالي `#D08A4E`، وB `#6F8A72`، وC `#9C8F63`، وD `#5E7A8C`، وF `#6D6580`. وحروف التير بخط العرض. والعنصر يستقر في مكانه بحركة spring، والنقاش الحر يبيّن نقطة بلون اللي حرّك.

## المكونات
- **الزر الرئيسي:** خلفية `--accent`، ونص `--accent-ink`، وارتفاع 44px (لمس مريح)، وزوايا 6px.
- **الزر الثانوي:** شفاف بحد `--line-strong`.
- **الحقول:** `--surface-2`، وحد سفلي يتلون بالكهرماني عند التركيز.
- **اللوحات:** `--surface` بحد رفيع، بدون ظل.
- **التحميل:** هياكل (skeletons) بنفس شكل المحتوى مع وميض خفيف، بدون دوائر دوارة.
- **الفراغ والخطأ:** أيقونة خطية كبيرة باهتة، وجملة واضحة، وزر للخطوة التالية.

## الجوال أولاً
كل صفحة تتصمم على 390px أول. خانة الإجابة ثابتة تحت الصورة ومرفوعة فوق الكيبورد. القائمة الجانبية (اللاعبين والشات) تنزل تحت المحتوى في الجوال.
