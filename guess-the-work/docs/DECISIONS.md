# القرارات (Decisions)

كل قرار أخذته بدون ما أسألك، مع السبب.

1. **مكان المشروع:** الجلسة مربوطة بمستودع `axrzw/apready` فقط (ما أقدر أنشئ مستودع جديد)، فبنيت «خمّن العمل» في مجلد مستقل `guess-the-work/` داخل نفس المستودع على الفرع `claude/relaxed-carson-dvd3d8`، بدون ما ألمس كود My Ready AP. تقدر تنقله لمستودع خاص فيه لاحقاً بـ `git subtree split --prefix guess-the-work`.
2. **الاسم:** «خمّن العمل» (طلبك: بدّل الاسم من «خمّنها»). الاسم البرمجي `guess-the-work`.
3. **قاعدة البيانات:** ما فيه Docker شغّال ولا Supabase CLI في البيئة، فاستخدمت SQLite المدمج في Node 22 (`node:sqlite`) بدون أي مكتبة native. كل الوصول للبيانات عبر واجهة `Repo` (`packages/db/src/repo.ts`). فيه `SupabaseRepo` بنفس الواجهة + `supabase/migrations/0001_init.sql`. التبديل بمتغير `DATA_BACKEND=supabase`.
4. **حزمة رابعة `packages/db`:** طبقة البيانات تحتاجها `ingest` و`web` معاً، فحطيتها حزمة مستقلة بدل ما تكون داخل الويب.
5. **الإصدارات:** Next 15.5 + React 19.1 + Tailwind 3.4 + TypeScript 5.9 + vitest 3.2 (إصدارات مستقرة معروفة؛ TypeScript 7 و Tailwind 4 و Next 16 جديدة ومخاطرة الليلة).
6. **المطابقة:** مسافة OSA (Levenshtein + تبديل حرفين متجاورين) على النص المطبّع بدون مسافات. الحد: ≤6 أحرف مطابقة تامة، 7–10 خطأ واحد، 11–16 خطآن، 17–24 ثلاثة، وأكثر أربعة. والمطابقة التقريبية تشترط نفس أول حرف (عشان Naruto ≠ Haruto). الموسم يتوحّد (`s2`) والجواب بالموسم يُقبل للعمل نفسه.
7. **طبقات الشهرة:** عتبات ثابتة لكل قسم (`packages/core/src/tiers.ts`) بدل النسب المئوية، عشان الطبقة ما تتغير كل ما كبرت المكتبة. hidden_gem = أقل من عتبة "mid" وتقييمه ≥ حد القسم.
