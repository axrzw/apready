# أسئلة لك (كمّلت بدون جوابها، واخترت الافتراضي المكتوب)

1. **وين تبي المشروع يعيش؟** حطيته في `guess-the-work/` داخل مستودع apready (ما أقدر أنشئ مستودع جديد من هنا). تبي أنقله لمستودع خاص مستقل؟ (أمر النقل في الـ README).
2. **الإيتشي (Ecchi):** مستبعد الـ isAdult والـ Hentai بس. تبي أستبعد Ecchi بعد، أو أخليه خيار في إعدادات الغرفة؟ (الافتراضي الحين: موجود).
3. **عتبات الشهرة:** المشهور عندي = 250 ألف عضو في AniList أو أكثر (≈ 326 عمل). تبيها أقل (مثلاً 150 ألف) عشان يصير فيه مشهور أكثر؟
4. **الدخول:** بقائمة آيديات ديسكورد (`ALLOWED_DISCORD_IDS`) أو بعضوية سيرفر الشلة (`ALLOWED_DISCORD_GUILD_ID`)؟ الاثنين مدعومين.
5. **الاستضافة:** Vercel ما يناسب (SSE طويل + ffmpeg + ملفات). أقترح VPS صغير أو Fly.io/Railway مع Supabase. وش تفضّل؟
6. **Steam و Letterboxd:** الحقول موجودة في صفحة الربط بس الاستيراد ما انكتب (Steam يبي مفتاح Web API وملف عام، Letterboxd ما عنده API رسمي). تبيها؟
7. **الصعوبة التلقائية:** الحين لو نسبة صحكم آخر 50 إجابة > 75% تنقص المشهور 5 نقاط لصالح المظلوم/المغمور، ولو < 35% العكس. مناسب؟
8. **نقاط الواصف:** 40% من نقاط كل مخمّن، وخصم 150 لكل كلمة ممنوعة. مناسب؟
