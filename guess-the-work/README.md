# خمّن العمل

موقع خاص لك وللشلة: تحديات «خمّن العمل» من الأنمي والألعاب والمسلسلات والأفلام والفجوال نوفل، غالباً وأنتم في مكالمة ديسكورد. الواجهة عربية (RTL) وفيها زر للإنجليزي.

- **18 طور تخمين:** الأوبننق، الإندنق، الأوست، الصوت المعدّل، المشهد (لقطة / مقطع صامت / مقطع بالصوت)، الصورة، البوستر (14 تأثير)، الظل، العيون، اسم الشخصية، الوسوم، القصة (الأسماء محجوبة)، مؤدي الصوت، الرابط المشترك، أعلى أو أقل، الترتيب الزمني، الدخيل، اسم الأغنية أو الفنان.
- **Mix:** تختار الأطوار اللي تبيها في جولة وحدة.
- **أطوار الحفلة:** الواصف (الكلمات الممنوعة تنحجب وتخصم) والرسّام (لوحة رسم، تخمين، تصويت، معرض).
- **مكتبة كبيرة ومتنوعة:** أكثر من 5,000 عمل و35 ألف شخصية، مقسومة على أربع طبقات شهرة: مشهور / متوسط / مظلوم / مغمور. نسبها في كل غرفة تتعدل (الافتراضي 25/30/30/15).
- **تلميحات** من الأعم للأدق، و**نقاط** حسب السرعة والصعوبة والتلميحات وطريقة الإجابة، مع سلسلة إجابات (streak)، وصعوبة تتعدل تلقائياً، ولوحة صدارة، وإحصائيات، وتحدي يومي، وزر «اعتمد جوابي».

## التشغيل على جهازك

المتطلبات: Node.js 22.13 أو أحدث، و pnpm 10. (ffmpeg ينزل لحاله مع `ffmpeg-static`.)

```bash
cd guess-the-work
pnpm install
cp .env.example apps/web/.env.local      # فيه GROUP_PASSWORD (محلياً الافتراضي "dev")
pnpm db:setup                            # migrations + المكتبة الجاهزة (5,189 عمل) في PGlite، بدون Docker
pnpm build && pnpm start                 # أو: pnpm dev
```

افتح http://localhost:3000، واكتب كلمة سر القروب (`dev` محلياً) واسمك. أول واحد يدخل يصير الأدمن (أو ادخل بـ `ADMIN_PASSWORD`).

**النشر على Vercel من الجوال:** `docs/DEPLOY.md`.

### سحب المكتبة من الصفر أو توسيعها

```bash
pnpm seed -- --anime 3600 --tvmaze 1000 --vndb 700     # تقريباً 20 دقيقة (يحترم حدود كل API)
pnpm seed -- --anime 0 --tvmaze 0 --vndb 0 --themes --media 300   # أغاني AnimeThemes + قص الصوت واللقطات والمقاطع
pnpm ocr -- --limit 2000                                # يكتشف النص على البوسترات عشان ينحجب
pnpm names                                              # يطبّق الأسماء العربية (packages/ingest/data/spacetoon.json)
pnpm weekly                                             # المهمة الأسبوعية (أو ENABLE_SCHEDULER=1)
```

مع مفاتيح TMDB و IGDB في `.env.local`، الأمر `pnpm seed` يسحب الأفلام والمسلسلات والألعاب بعد.

### الاختبارات

```bash
pnpm test          # 226 اختبار: المطابقة، الإكمال، النقاط، الغرف، الطول والتمديد، الأطوار، خط الصوت (ffprobe)، المصادر، منع الإيموجي
pnpm lint && pnpm typecheck && pnpm build
# E2E بـ 3 متصفحات (السيرفر شغّال مع E2E_SECRET في .env.local):
E2E_SECRET=... ADMIN_PASSWORD=... pnpm e2e
```

## البنية

```
guess-the-work/
  apps/web           Next.js 15 (App Router) + Tailwind، الموقع والـ API والغرف (SSE)
  packages/core      كل منطق اللعبة بدون واجهة: المطابقة، الطبقات، الاختيار، التلميحات، النقاط،
                     بناء الأسئلة لكل طور، محرك الغرف، الواصف، الرسّام (جاهز لبوت ديسكورد)
  packages/db        طبقة البيانات: واجهة Repo + Drizzle (PGlite محلياً، Neon في الإنتاج) + migrations
  packages/ingest    سحب البيانات (AniList, Wikidata, Kitsu, Jikan, AnimeThemes, TVmaze, VNDB, TMDB, IGDB)،
                     ffmpeg (صوت/لقطات/مقاطع)، sharp (التأثيرات)، tesseract.js (OCR)، المهمة الأسبوعية
  e2e/               اختبارات Playwright بـ 3 لاعبين
  snapshot/          المكتبة الجاهزة مضغوطة
  docs/              الخطة، القرارات، الأسئلة، العوائق، تقرير الصباح
```

### كيف يمنع كشف الجواب
- التصحيح كله على السيرفر. المتصفح ما يوصله اسم الجواب ولا أي خيار مكتوب عليه إنه الصح.
- الصور والأصوات توصل بروابط عشوائية (`/api/m/<token>`)، والسيرفر يرسم التأثير؛ الأصل ما يوصل إلا بعد نهاية السؤال.
- الكشف التدريجي يحسبه السيرفر من الوقت، فما ينفع تطلب «الدرجة الأخيرة» قبل وقتها.
- عناصر الواصف والرسّام الخاصة روابطها مقفلة على صاحبها.
- الاقتراحات أثناء الكتابة تجي من المكتبة كلها، مو من الجواب.
